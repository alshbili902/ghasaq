# عالم سوسو الأدبي — من دحوم إلى سوسو

تطبيق ويب أدبي خاص وعاطفي باللغة العربية، صُمّم كهدية رقمية شخصية من **دحوم إلى سوسو**؛ ليكون مساحةً هادئةً تلجأ إليها في أوقات الدراسة والاختبارات والتعب النفسي.

---

## المزايا الرئيسية

1. **مدخل رئيسي سينمائي (`/`):**
   - الهوية اللونية الليلية الهادئة (`#07060B`, `#0D0A14`, `#21152F`, `#A994D8`, `#111A30`, `#A9D9F5`, `#F3EEF9`, `#B5ACBF`).
   - النصوص الأصلية المحددة والاقتباس الموقع من دحوم إلى سوسو.
   - زران رئيسيان فقط للتنقل (`افتحي رسالتكِ` و`إلى عالمكِ الجميل`) دون أي عناصر تشتيت إضافية.
2. **إهداء أغنية «فاكر — إليسا» (`components/music/MusicInvitation.tsx`):**
   - نافذة سينمائية تظهر تلقائيًّا في الزيارة الأولى خلال الجلسة (`sessionStorage`).
   - تشغيل عبر التضمين الرسمي الموثّق من يوتيوب لقناة إليسا الرسمية (`f7mgm_sRdaA`) وقناة روتانا الرسمية (`zp5wgtm9uHI`) فقط بعد موافقة سوسو الصريحة (`لنستمع إليها معًا`)، مع بديل مباشر موثّق في حال قيود المتصفح.
3. **كون الجزيئات المتحركة (`components/background/ParticleUniverse.tsx`):**
   - خلفية `Canvas` مخصصة تستجيب لحركة المؤشر والتمرير (`Parallax`).
   - تدعم تقليل الحركة (`prefers-reduced-motion`) وتقليل كثافة الجزيئات على الهواتف وإيقاف الحلقة عند إخفاء التبويب.
4. **قسم الرسائل الشخصية (`/letters` و `/letters/[slug]`):**
   - 12 رسالة عربية أدبية أصلية موزّعة على 10 تصنيفات وجدانية ودراسية.
   - ميزة «رسالة عشوائية لهذه اللحظة» ونسخ الاقتباسات والتنقل بين الرسائل.
5. **المكتبة الأدبية والتأملات (`/library` و `/library/[slug]`):**
   - 11 مقالًا أدبيًّا متكاملًا متعدد المحاور موزّعة على 10 تصنيفات.
   - بحث فوري في العناوين والمحتوى (يدعم تطبيع الحروف العربية والتشكيل)، وتصفية بالتصنيفات، ومؤشر تقدّم القراءة، واقتباسات قابلة للنسخ، ومقالات ذات صلة.

## متطلبات التشغيل المحلي

تأكد من وجود **Node.js 18.18+** (أو Node.js 20/22/24).

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل بيئة التطوير المحلية
npm run dev

# 3. فحص الأنواع البرمجية (TypeScript)
npm run lint

# 4. بناء نسخة الإنتاج
npm run build

# 5. تشغيل خادم الإنتاج محليًّا
npm run start
```

> **ملاحظة لمستخدمي Windows PowerShell:** في حال كانت سياسة تنفيذ السكربتات (`ExecutionPolicy`) تمنع تشغيل `npm.ps1`، يمكنك استخدام `npm.cmd install` و `npm.cmd run dev` و `npm.cmd run build`.

## الإعدادات الاختيارية والنشر (Deployment)

يمكن نشر المشروع مباشرةً على **Vercel** أو **Netlify** أو أي منصة تدعم تطبيقات Next.js:

- `NEXT_PUBLIC_SITE_URL`: (اختياري) ضع فيه النطاق النهائي للموقع عند نشره (مثال: `https://example.com`) لتوليد الروابط القانونية (`Canonical URLs`) وملف `sitemap.xml` بالنطاق الفعلي.
- `NEXT_PUBLIC_FAKER_YOUTUBE_ID`: (اختياري) معرّف الفيديو الرسمي لأغنية «فاكر — إليسا» على يوتيوب، مضبوط افتراضيًّا على النسخة الرسمية الموثّقة في قناة إليسا (`f7mgm_sRdaA`).
